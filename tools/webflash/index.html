2. Fleet key

A fleet key binds all boards you flash from this browser into one private network. Each fleet name gets its own 16-byte key, kept in this browser’s localStorage.

Key fingerprint (SHA-256)
—
Keep your key safe. Losing the exported key orphans this fleet — boards can no longer join it, and you cannot rejoin them from this browser. A full-chip erase wipes the firmware and the fleet key baked into the board, returning it to an unprovisioned state; the fleet keys saved in this browser (and any exported .hex) are untouched — re-flash with the same fleet to re-bind the board. To move to a new browser, export the key first, then import it there.

Erasing a board: erase happens in the installer’s first-install dialog: when you connect a board for the first time, tick the “Erase device” option in that dialog to wipe it (firmware + fleet key) before the new image is written.

3. Flash

Selecting a role and a fleet patches that role’s released image with your fleet key, then hands it to the web installer. On first connect your browser will ask for permission to use the USB device; click Connect and, if the board does not auto-reset, hold its BOOT button while the dialog opens.
